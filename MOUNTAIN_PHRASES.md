# Mountain dashboard greetings

100 additional mountain-themed phrases. Mountain mixes these with the original 100 greetings, filtered by season and time of day.

Changes at **06:00, 12:00 and 18:00 Europe/Prague**. The evening phrase stays overnight.

Editable source: `public/mountain-phrases.json`. Restart the Python server after editing.
